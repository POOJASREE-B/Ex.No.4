## INTRODUCTION

This experiment focuses on advanced prompting strategies including:

Comparative Analysis Prompt
Experiential Perspective Prompt
Everyday Functioning Prompt

Prompt Refinements
Prompt Size Limitations

These techniques help improve AI response quality, clarity, and efficiency.

## 2. EXPERIENTIAL PERSPECTIVE PROMPT
# Definition
Experiential prompts ask the AI to answer from a particular viewpoint or role.
# Example Prompt
As a factory manager, explain the benefits of using IoT automation in manufacturing industries.

# AI Response
As a factory manager, IoT automation helps improve machine monitoring, reduces downtime, increases production efficiency, and lowers maintenance costs through predictive maintenance systems.

# Features

Context-aware responses
Human-like perspective
Practical explanations

## 3. EVERYDAY FUNCTIONING PROMPTS
# Definition
Everyday Functioning Prompts explain how technology is used in daily life or real-world systems.

#Example Prompt
Describe how IoT sensors are used in everyday smart home systems.

# AI Response
IoT sensors are used in smart homes to control lighting, monitor temperature, detect motion, and improve energy efficiency through automated systems.

# Applications

Smart homes
Smart watches
Smart traffic systems
Industrial automation

## 4. UNIVERSAL PROMPT STRUCTURES
# Definition
Universal prompts follow a general template applicable to multiple topics.

# Example Prompt 1
Explain predictive maintenance in simple terms with an example.

# AI Response
Predictive maintenance is a method of predicting machine failures before they happen using sensor data and AI analysis. For example, vibration sensors in factory machines can detect abnormal behavior and alert technicians before breakdown occurs.

## 5. PROMPT REFINEMENTS
# Definition
Prompt Refinement improves prompts to obtain clearer and more accurate AI responses.

# Initial Prompt
Explain automation.

# Refined Prompt
Explain industrial automation in manufacturing industries with examples of IoT sensors and predictive maintenance.

# Observation
Prompt Type	Output Quality
Basic Prompt	General response
Refined Prompt	Detailed and accurate response

## 6. PROMPT SIZE LIMITATIONS
# Definition
Large prompts may exceed AI processing limits. Breaking prompts into smaller chunks improves efficiency and clarity.

# Example 1
Large Prompt
Explain 100 applications of Artificial Intelligence.

# Refined Prompt
Explain 10 applications of Artificial Intelligence at a time.

# Example 2
Large Prompt
Translate a 5000-word industrial report into Tamil.

# Refined Prompt
Translate the first 1000 words of the industrial report into Tamil, then continue section by section.
